Sparkplug B

Act as a Sparkplug edge node over MQTT for Ignition and other SCADA hosts.
Loading…
Publishes device data as Sparkplug B over the MQTT broker configured above, so a Sparkplug host (Ignition, Honeywell EBI, …) can consume it without an industrial gateway in between. Enable MQTT first.
Only the host STATE topic differs.
Required. Must not contain /, + or #.
Defaults to this device's serial number.
Set to expose the metrics as a child device (DBIRTH/DDATA).
Rebirth automatically when this host comes back online.
Every metric is declared in the birth certificate. Bind one to a device event to publish it automatically whenever the value changes, or leave it unbound and drive it from a Sparkplug B Publish rule action.

Location

Camera position for Sunrise / Sunset triggers.
North is positive (e.g. 59.3293), South is negative (e.g. −33.8688). Used by Sunrise/Sunset triggers.
East is positive (e.g. 18.0686), West is negative (e.g. −73.9442).
